    LOCAL BUILD NOTES

    Help and walkthrough controls

    These controls exist only to exercise the synthetic prototype states.

    CLINICAL TIME

    When does time move?

    Only a committed Continue time action advances the Gate A clock. Reading, opening a released artifact, navigating, citing, and leaving feedback use zero clinical time.

    Every result is labeled with the acquisition and release time supplied by the synthetic authority.

    SYNTHETIC SCENARIOS

    Walkthrough controls

    Change these controls to reach blocked and recovery states. They do not connect to a provider.

    INFORMATION SOURCES

    Patient report and chart

    A statement from the patient is shown as patient-reported. The chart uses verified, measured, unknown, and not-measured labels when the fixture provides those states.

    No values in Fixture-A are medical measurements.

    ACCESSIBILITY

    Keyboard and text access

    Controls use native buttons, fields, and selects. The trace has a plotted and text representation. Status messages use live regions and the layout reflows for narrow screens and zoom.
