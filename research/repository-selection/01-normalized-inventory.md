# Stage 1 — Normalized inventory

**Source baseline:** supplied canonical repository/research document v1.1, reviewed 19 November 2026. **Count integrity:** this matrix keeps 96 GitHub + 7 GitLab + 6 Hugging Face code/model + 2 Hugging Face dataset + 1 canonical Orthanc Mercurial repository = 112 tracked primary-host entries. Supplemental leads are separate and do not change that count.

**Fields:** stable local ID, canonical upstream, primary role/capability, first-slice relevance (0/1/2), provisional reuse surface, rights and privacy flags, fork/dependency relationships, evidence grade/date, and disposition. The 0/1/2 flag prioritizes experiments; it is not a quality score. Reuse surfaces for non-shortlisted rows are desk estimates or explicitly unknown, not verified APIs. The 96-row inherited inventory's source evidence remains at the 19 November audit unless a Stage 2 card says otherwise.

**Plan v2.2 scope:** local `A-source` is a source-inspection qualifier, not a standalone v2.2 evidence grade; it names only the pinned source path, source text, license file, or reuse seam inspected. `B`, `C`, and `D` retain the v2.2 meanings, with source/date recorded. Runtime behavior is `not-tested` unless a later experiment record says otherwise. Dispositions use v2.2 outcomes where decided; `shortlist` is Stage 2 pool membership only and carries no eligibility or execution approval. Historical `backlog`/`defer` notes indicate `conditional` future-scope status; the reason remains in the row.

**Privacy:** no full-inventory patient-data or bundled-media audit was performed. Use synthetic/cleared fixtures only. Software licenses do not grant rights to data, cases, scans, waveforms, images, weights, dependencies, or generated outputs.

## Relationship and duplication rules retained

- Epicurrents GH-35 through GH-41 are related components of one workstation family, not seven full games.
- BioGears GH-56 and Kitware Pulse GL-01 are separate engines; Pulse is a historical fork, not a synchronizing mirror.
- OHIF GH-27 Cornerstone3D is a supporting renderer; GH-96 ohif-core is archived/legacy. Orthanc MC-01 is a server, not an image viewer.
- SimEHR source and sample-chart licenses differ. GTAgentClinic code and CC BY case content differ. Open Sim Lab code and individual scenario/content licenses differ.
- OTC-Flow GH-21 and HF-02 are source/weights counterparts. Orthanc GitHub mirrors are not new canonical projects. Supplementals are not added to the 112 count.
- GH-67 paultman/patientSimulator was corrected to MIT in the supplied v1.1 audit; third-party content rights remain separate.
